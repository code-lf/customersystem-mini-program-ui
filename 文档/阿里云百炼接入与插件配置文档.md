## 一、 图片页面（MCP 管理 / 创建 MCP 服务）录入指南

如果您在阿里云百炼的 **【组件】->【MCP 管理】->【创建 MCP 服务】** 页面录入，请按以下内容直接填写：

| 表单字段 | 建议填写内容 | 说明 |
| :--- | :--- | :--- |
| **服务名称 \*** | `格宏智能电器选型与商品服务` | 简明标识该服务为格宏空调电器核心接口 |
| **服务描述 \*** | `提供格宏暖通空调商品检索、技术规格参数查询、分类树查看以及报价方案草稿生成的MCP工具集。` | 便于大模型与百炼平台理解该服务能力 |
| **插件 URL \*** | `https://您的后端业务域名/api/mcp/sse` 或 `https://您的后端业务域名/api` | 您的生产/开发后端服务对外可访问的 URL 地址 |
| **Header 列表** | Key: `Authorization`<br>Value: `Bearer 您的后端业务访问Token`（若无需鉴权可留空） | 用于保护您的后端 API 安全 |

> **提示**：如果您是配置标准的 HTTP RESTful 插件（组件管理 -> 自定义插件/工具），请参考下方的第二节。

## 二、 百炼组件管理 / 自定义 API 插件录入指南

### 工具 1：商品搜索与选型 (`search_products`)【已有】

- **项目现状**：✅ **已有**（对应项目接口 `GET /crm/quote/product/goods`）
- **工具名称 (Name)**：`search_products`
- **中文展示名**：商品搜索与选型匹配
- **工具描述 (Description)**：
  > 检索暖通空调商品库。当用户询问机型推荐（如按面积、匹数、系列、冷暖、价格选型）或查找具体空调型号时调用。
- **请求方法**：`GET`
- **接口路径**：`/crm/quote/product/goods`

#### 请求参数列表（Query Parameters）：

| 参数名称 | 类型 | 必填 | 默认值 | 参数描述 |
| :--- | :--- | :---: | :---: | :--- |
| `keyword` | `string` | 否 | - | 搜索关键词或型号（如 GMV、KFR-35GW、冷静王、云佳） |
| `pishu` | `string` | 否 | - | 空调匹数（如 1.5匹、2匹、3匹、5匹） |
| `mianji` | `string` | 否 | - | 适用面积范围（如 15-25、30-50） |
| `category_id` | `integer`| 否 | - | 分类ID（如 14家用空调、40大多联、33空气能） |
| `product_type`| `string` | 否 | - | 产品大类：`home`（家用空调）、`central`（中央空调/多联机） |
| `nengxiao` | `string` | 否 | - | 能效等级（如 1级、3级、新一级） |
| `lengnuan` | `string` | 否 | - | 冷暖类型（如 冷暖、单冷） |
| `page` | `integer`| 否 | 1 | 页码，默认 1 |
| `limit` | `integer`| 否 | 6 | 每页返回条数，推荐 5-10 条 |

#### 返回字段核心结构：
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "total": 12,
    "list": [
      {
        "id": 400,
        "goodsname": "格力清巧风72GAf变频3级",
        "type": "KFR-72GW/(72563)FNhAf-B3JY01",
        "category_name": "格力家用空调",
        "pishu": "3匹",
        "mianji": "32-50",
        "nengxiao": "3级",
        "lengnuan": "冷暖",
        "price": 6500,
        "zhileng": "7270W",
        "zhire": "9210W",
        "fenbei": "45dB"
      }
    ]
  }
}
```

### 工具 2：商品技术参数详情 (`get_product_detail`)【已有】

- **项目现状**：✅ **已有**（对应项目接口 `GET /crm/quote/product/goods/{id}`）
- **工具名称 (Name)**：`get_product_detail`
- **中文展示名**：商品详细技术规格
- **工具描述 (Description)**：
  > 根据商品 ID 精确获取该电器的全部技术参数。当用户询问某机型的具体尺寸、噪音分贝、冷媒型号、管径规格、电源要求或电辅热功率时调用本工具。
- **请求方法**：`GET`
- **接口路径**：`/crm/quote/product/goods/{id}`

#### 路径参数（Path Parameter）：

| 参数名称 | 类型 | 必填 | 参数描述 |
| :--- | :--- | :---: | :--- |
| `id` | `integer` | 是 | 商品的唯一 ID 编号（例如 400） |

#### 返回关键技术参数说明：
- `goodsname`: 商品名称
- `type` / `model`: 官方型号
- `price`: 指导售价
- `pishu`: 匹数
- `mianji`: 适用面积 (㎡)
- `in_size` / `out_size`: 室内机 / 室外机尺寸 (宽*高*深 mm)
- `in_wet` / `out_wet`: 室内机 / 室外机重量 (kg)
- `fenbei`: 运行噪音 (dB)
- `lengmei`: 制冷剂型号（R32 / R410A）
- `pipeline`: 铜管管径（液管/气管）
- `guige`: 电源规格（220V/380V）

### 工具 3：产品分类体系 (`get_product_categories`)【已有】

- **项目现状**：✅ **已有**（对应项目接口 `GET /crm/quote/product/category/tree`）

- **中文展示名**：获取产品类目分类树
- **工具描述 (Description)**：

- **请求方法**：`GET`
- **接口路径**：`/crm/quote/product/category/tree`
- **请求参数**：无

### 工具 4：创建报价单草稿 (`create_quote_solution`)【已有】

- **项目现状**：✅ **已有**（对应项目接口 `POST /crm/quote`）
- **工具名称 (Name)**：`create_quote_solution`
- **中文展示名**：创建选型报价单草稿
- **工具描述 (Description)**：
  > 协助用户将推荐选定的多款空调商品组合生成一份报价方案单草稿。
- **请求方法**：`POST`
- **接口路径**：`/crm/quote`

#### 请求 Body (JSON)：

| 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :---: | :--- |
| `title` | `string` | 是 | 方案标题（如：张先生120㎡三室两厅选型报价方案） |
| `customerName` | `string` | 否 | 客户姓名 |
| `discount` | `number` | 否 | 折扣比例（如 95 代表95折，默认100） |
| `items` | `array` | 是 | 商品列表 |
| `items[].productId` | `integer` | 是 | 商品 ID |
| `items[].quantity` | `integer` | 是 | 选购台数 |
| `items[].remark` | `string` | 否 | 安装位置或备注（如：客厅、主卧、次卧） |

## 三、 智能体应用角色设定 (System Prompt)

在百炼应用的 **【应用配置】->【Prompt / 角色设定】** 中直接复制粘贴：

```text
你是一位专业的暖通与智能电器销售选型专家（格宏小助手）。
你的核心任务是为客户提供严谨的空调选型配置、技术参数答疑、安装配合要求分析以及初步报价预算制定。

【工作规范】：
1. 当用户提出选型需求（如“120平米3室2厅怎么配空调”、“主卧20平米推荐一款冷暖变频”）时：
   - 快速根据房间面积估算冷量负荷（一般住宅建议 180W~220W/㎡，顶楼/大玻璃适当上浮）；
   - 主动调用 `search_products` 检索契合匹数与面积的商品；
   - 结构化呈现推荐机型：包含商品名称、型号、匹数、适用面积、能效及亮点。

2. 当用户询问具体型号的细节（如“外机尺寸多大”、“管径是多少”、“噪音几分贝”）时：
   - 务必调用 `get_product_detail` 获得官方精确数据，严禁凭空编造技术参数。

3. 当用户确认选型要求汇总报价单时：
   - 协助整理包含各房间机型、数量、预估单价的清单，并可调用 `create_quote_solution` 生成方案草稿。

4. 回复风格：专业、严谨、排版清爽，重点参数清晰易读。
```
